Closing creation form

Creating a closing is a two-step process. On this page, users provide the closing details and specify the closing parties and documents. On the following page, users stipulate which documents should be signed by each party.

Name

  • The name must be maximum 255 characters long

Time

Region

The region will determine the time zone of the closing. All timestamps displayed are set in reference to that time zone.

Location

Expiration time

The parties are permitted to sign the closing documents until a specified timestamp. If this field is left empty, the default expiration time is set as the closing time plus an additional 30 calendar days.

All fields, excluding the expiration time, are mandatory.
