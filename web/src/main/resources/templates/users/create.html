User creation form

With this form, users are added to the organisation.

First name

  • The first name must be a maximum of 255 characters long.
  • The first name provided must match the one mentioned on the user's electronic identity card. If the user has multiple first names, please only save the first one.

Last name

  • The last name must be a maximum of 255 characters long.
  • The last name provided must match the one mentioned on the user's electronic identity card.

Email

  • The email address must be valid.

Date of birth

  • The date of birth must match the one mentioned on the user's electronic identity card.
