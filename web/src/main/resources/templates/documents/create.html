Document creation form

With this form, users upload documents which will be signed during closings.

Filename input field

The filename should:

  • Be maximum 255 characters long.
  • Contain only alphanumeric characters.
  • Use underscores ("_") or hyphens ("-") instead of spaces between words.

File input field

The file should:

  • Be maximum 100 MB big.
  • Be in PDF format if meant to be signed using PAdES.
