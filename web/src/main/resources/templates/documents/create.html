Document creation form

With this form, users upload documents which will be signed during closings.

Filename

  • The filename must be maximum 255 characters long
  • It must only contain alphanumeric characters.
  • Use underscores ("_") or hyphens ("-") instead of spaces between words.

File

  • The file size must not exceed 100 MB.
  • The file must be in PDF format if meant to be signed using PAdES.

All fields are mandatory.
